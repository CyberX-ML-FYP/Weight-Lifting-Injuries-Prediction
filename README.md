## Data Science Project Template

You can use this template to structure your Python data science projects. It is based on [Cookie Cutter Data Science](https://drivendata.github.io/cookiecutter-data-science/).

## Folder structure

```
data-science-template/
  .gitignore
  README.md
  requirements.txt
  environment.yml
  data-science-template.code-workspace
  data/
    external/
    interim/
    processed/
    raw/
      .gitkeep
      videos/
  docs/
  models/
  notebooks/
  references/
    folder_structure.txt
  reports/
    figures/
  src/
    __init__.py
    data/
      __init__.py
      .gitkeep
      make_dataset.py
    features/
      __init__.py
      .gitkeep
      build_features.py
    models/
      __init__.py
      .gitkeep
      predict_model.py
      train_model.py
    visualization/
      __init__.py
      .gitkeep
      plot_settings.py
      visualize.py
```
